Examples

if (GibInvoiceQrCode.TryParse(scannedText, out GibInvoiceQrCode? qr))
{
    qr.Number.ToString(); // "ABC2026000000001"
    qr.PayableAmount;     // 120.00
    qr.VatAmounts[20m];   // 20.00
}

Remarks

The QR code holds a flat JSON object such as {"vkntckn":"4840847211","avkntckn":"11111111111","senaryo":"EARSIVFATURA","tip":"SATIS","tarih":"2026-10-15","no":"ABC2026000000001","ettn":"51d3bb18-9650-4c8e-825d-5a7f845be630","parabirimi":"TRY","malhizmettoplam":"100.00","kdvmatrah(20)":"100.00","hesaplanankdv(20)":"20.00","vergidahil":"120.00","odenecek":"120.00"}.

TryParse(string?, out GibInvoiceQrCode?) checks the fields that identify the invoice: the seller VKN or TCKN, the buyer VKN or TCKN ("11111111111" for e-Arşiv buyers without one), the invoice number, the ETTN and the date. Amounts are optional. The method reads the text only; it does not ask GİB whether the invoice exists.
