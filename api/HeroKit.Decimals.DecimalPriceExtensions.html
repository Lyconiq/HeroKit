Class DecimalPriceExtensions

Namespace
HeroKit.Decimals
Assembly
HeroKit.dll

Provides price rounding, percentage and VAT helpers for decimal values. Methods return unrounded values unless a decimals argument is given. Callers round money with Math.Round(x, 2, MidpointRounding.AwayFromZero).

ExcludeVat(decimal, decimal, int?)

Removes VAT from a gross amount: gross / (1 + rate / 100).

public static decimal ExcludeVat(this decimal grossAmount, decimal ratePercent, int? decimals = null)

Parameters

grossAmount decimal

The gross amount.

ratePercent decimal

The VAT rate in percent. Must not be negative.

decimals int?

When given, rounds the result to this many decimals with AwayFromZero. Otherwise the result is not rounded.

Returns

decimal

The net amount.

Examples

120m.ExcludeVat(20m); // 100

Exceptions

ToPsychologicalPrice(decimal, decimal)

Raises a price to the next price that ends with the given fraction (for example 12.99). The result is floor(value) + ending, plus 1 if that is below the value.

public static decimal ToPsychologicalPrice(this decimal value, decimal ending = 0.99)

Parameters

value decimal

The price. Must not be negative.

ending decimal

The fractional ending, from 0 up to but not including 1. The default is 0.99.

Returns

decimal

The psychological price that is greater than or equal to value.

Examples

12.30m.ToPsychologicalPrice(); // 12.99
12.60m.ToPsychologicalPrice(0.50m); // 13.50

Exceptions

ArgumentOutOfRangeException

Thrown when value is negative or ending is outside [0, 1).
