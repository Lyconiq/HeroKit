Examples

using var stream = File.OpenRead("photo.bin");
FileTypes.Detect(stream)?.MimeType;           // "image/png"
FileTypes.FromExtension("report.docx")?.Name; // "Word document"
FileTypes.GetMimeType("archive.tar.gz");      // "application/gzip"
FileTypes.CheckUpload(stream, "photo.png").IsSafe;

Remarks

The static methods use Default. Inject a FileTypeRegistry or an UploadValidator instead when you want your own set of types or depend on them through constructor injection.

ToSafeFileName(string?, string)

Turns an uploaded file name into one that is safe to save or to send in a Content-Disposition header.

public static string ToSafeFileName(string? fileName, string fallback = "file")

Parameters

fileName string

The file name as uploaded, or null.

fallback string

The name returned when nothing is left. Defaults to "file".

Returns

string

The safe file name.

Examples

FileTypes.ToSafeFileName("../../etc/passwd");      // "passwd"
FileTypes.ToSafeFileName("C:\\temp\\rapor?.pdf");  // "rapor_.pdf"
FileTypes.ToSafeFileName("con.txt");               // "_con.txt"
FileTypes.ToSafeFileName("  Fatura  Ekim .pdf ");  // "Fatura Ekim .pdf"

Remarks

Keeps only the name after the last path separator. Replaces control characters and the characters Windows does not allow (\ / : * ? " < > |) with an underscore, collapses runs of white space into one space, and trims spaces and dots at both ends. Puts an underscore before Windows device names such as "CON" or "nul.txt", and cuts the name to 255 characters, keeping a short extension. Letters of every language are kept. This does not check the type: use CheckUpload(Stream, string) for that, and prefer a generated name for the stored file.
