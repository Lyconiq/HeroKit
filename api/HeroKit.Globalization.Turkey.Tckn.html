A Turkish identity number (T.C. Kimlik Numarası) that has passed the checksum check. Validate once at the edge, then pass the value around.

Examples

Tckn id = Tckn.Parse("10000000146");
id.Value;             // "10000000146"
id.ToMaskedString();  // "10*******46"

app.MapGet("/people/{id}", (Tckn id) => ...); // invalid numbers return 400

Remarks

Create values with Parse(string) or TryParse(string?, out Tckn). The type implements IParsable<TSelf>, so ASP.NET Core minimal APIs bind it from route and query values, and it has a JSON converter and a type converter for MVC model binding and configuration.

default(Tckn) holds no number: IsEmpty is true and Value is an empty string.
