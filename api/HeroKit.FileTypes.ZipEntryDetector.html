Examples

new ZipEntryDetector("word/");                                       // DOCX
ZipEntryDetector.ForMimeTypeEntry("application/vnd.oasis.opendocument.text"); // ODT

Remarks

The detector reads entry names without decompressing anything: the local file headers from the start of the file and, when FileTypeRegistry reads a seekable stream, the central directory at the end of the file. From a span with only the first bytes, later entries are not seen, so give ZIP-based types the ZIP type as Parent.
