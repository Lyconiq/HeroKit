Mask(string?, int, char)

Hides all but the last characters of a string, for example a card number, phone number or IBAN.

public static string? Mask(this string? value, int visibleCount = 4, char maskChar = '*')

Parameters

value string

The string to mask.

visibleCount int

The number of non-whitespace characters to keep visible at the end.

maskChar char

The character that replaces hidden characters. Defaults to '*'.

Returns

string

The masked string, or null if value is null.

Examples

"5321234567".Mask();        // "******4567"
"0532 123 45 67".Mask(2);   // "**** *** ** 67"

Remarks

Whitespace is kept and not counted, so formatted values keep their layout: "TR33 0006 1005" becomes "**** **** 1005".

Exceptions

ArgumentOutOfRangeException

visibleCount is negative.

MaskMiddle(string?, int, int, char)

Hides the middle of a string and keeps characters visible at both ends, for example a national id, IBAN or phone number in logs.

public static string? MaskMiddle(this string? value, int visibleStart, int visibleEnd, char maskChar = '*')

Parameters

value string

The string to mask.

visibleStart int

The number of non-whitespace characters to keep visible at the start.

visibleEnd int

The number of non-whitespace characters to keep visible at the end.

maskChar char

The character that replaces hidden characters. Defaults to '*'.

Returns

string

The masked string, or null if value is null.

Examples

"10000000146".MaskMiddle(2, 2);                      // "10*******46"
"TR33 0006 1005 1978 6457 8413 26".MaskMiddle(4, 4); // "TR33 **** **** **** **** **13 26"
"0532 123 45 67".MaskMiddle(4, 2);                   // "0532 *** ** 67"

Remarks

Whitespace is kept and not counted, so formatted values keep their layout. When the string has no more non-whitespace characters than visibleStart and visibleEnd together, every character is hidden, so a short value is never shown whole.

Exceptions

ArgumentOutOfRangeException

visibleStart or visibleEnd is negative.

RemoveDiacritics(string?)

Removes diacritics from Latin letters: "Çağdaş Şehir" becomes "Cagdas Sehir", "Ilıca" becomes "Ilica", "Łódź" becomes "Lodz".

public static string RemoveDiacritics(this string? value)

Parameters

value string

The string.

Returns

string

The string without diacritics, or an empty string if value is null.

Remarks

Uses a fixed character table instead of Unicode normalization, so the result does not depend on ICU and is the same with invariant globalization. Covers Turkish, Latin-1 and common Central European letters; other characters are kept.

ToTitleCase(string?, CultureInfo)

Converts a string to title case with the casing rules of the given culture.

public static string ToTitleCase(this string? value, CultureInfo culture)

Parameters

value string

The string to convert.

culture CultureInfo

The culture whose casing rules are used, for example tr-TR for İ/ı.

Returns

string

The title-cased string, or an empty string if value is null.

Examples

"istanbul ılıca".ToTitleCase(CultureInfo.GetCultureInfo("tr-TR")); // "İstanbul Ilıca"
"HELLO WORLD".ToTitleCase(CultureInfo.InvariantCulture);          // "Hello World"

Remarks

Words start after whitespace or a hyphen. The first letter of each word is upper-cased and the rest is lower-cased, so all-caps input is converted too (unlike ToTitleCase(string)). Letters after an apostrophe stay lower case: "istanbul'da" becomes "İstanbul'da" with tr-TR.

Truncate(string?, int, string)

Shortens a string to a maximum length and appends an ellipsis when it was cut.

public static string? Truncate(this string? value, int maxLength, string ellipsis = "…")

Parameters

value string

The string to shorten.

maxLength int

The maximum length of the result.

ellipsis string

The text appended when the string is cut. Defaults to "…".

Returns

string

The original string if it fits; otherwise the shortened string. Null if value is null.

Examples

"HeroKit extensions".Truncate(10);      // "HeroKit e…"
"HeroKit".Truncate(10);                 // "HeroKit"

Remarks

The result, including the ellipsis, is never longer than maxLength. The cut never splits a surrogate pair, so emoji and other characters outside the BMP stay intact.

Exceptions

ArgumentOutOfRangeException

maxLength is shorter than ellipsis.
