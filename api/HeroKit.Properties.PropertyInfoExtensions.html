TrySetConvertedValue(PropertyInfo, object?, object?)

Converts a value to the property type and sets it on an instance.

public static bool TrySetConvertedValue(this PropertyInfo property, object? instance, object? value)

Parameters

property PropertyInfo

The property to set.

instance object

The instance that owns the property, or null for a static property.

value object

The value to convert and set.

Returns

bool

True if the value was converted and set; otherwise false.

Examples

typeof(Order).GetProperty("Quantity")!.TrySetConvertedValue(order, "42"); // order.Quantity == 42

Remarks

Conversion follows TryConvertTo<T>(object?, out T?). Null is set only on properties that accept null.
