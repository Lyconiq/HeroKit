Remarks

Null and empty values pass, so optional properties stay optional. Combine with NotEmpty() to require a value. Messages use the FluentValidation placeholder {PropertyName} and can be replaced with WithMessage. Country rules take a Country, for example Turkey.

SafeUpload<T, TFile>(IRuleBuilder<T, TFile?>, Func<TFile, Stream>, Func<TFile, string>, UploadPolicy?)

Validates an uploaded file with UploadValidator: file name, program or script content, content that does not fit the extension, macros, active SVG content, size and allowed types, as set in policy.

public static IRuleBuilderOptions<T, TFile?> SafeUpload<T, TFile>(this IRuleBuilder<T, TFile?> ruleBuilder, Func<TFile, Stream> openRead, Func<TFile, string> fileName, UploadPolicy? policy = null) where TFile : class

Parameters

Returns the file name as uploaded.

The upload policy; null uses Default.

Returns

IRuleBuilderOptions<T, TFile>

The rule builder options, for chaining.

Type Parameters

T

The validated object type.

TFile

The file type.

Examples

var imagesOnly = new UploadPolicy { AllowedTypes = [FileTypes.Jpeg, FileTypes.Png], MaxLength = 5 * 1024 * 1024 };
RuleFor(x => x.Photo).NotNull().SafeUpload(f => f.OpenReadStream(), f => f.FileName, imagesOnly);

Remarks

Works with any file type: give a function that opens the content and one that returns the file name, for example for ASP.NET Core's IFormFile or Blazor's IBrowserFile. The rule opens the stream, reads what the check needs and disposes it. A null file passes; add NotNull() to require one. The message is '{PropertyName}' is not accepted: {UploadMessage}, where {UploadMessage} is Message; replace it with WithMessage.
