Examples

var validator = new UploadValidator(new UploadPolicy { AllowedTypes = [FileTypes.Jpeg, FileTypes.Png] });

UploadCheckResult result = validator.Validate(file.OpenReadStream(), file.FileName);
if (!result.IsSafe)
    return BadRequest(result.Message);

Remarks

The checks run as a chain, in this order, and the first rejection stops it: file name, program or script extension (also hidden as in "a.php.jpg"), empty content, MaxLength, program or script content, known extension, detected content and whether it fits the extension, AllowedTypes, macros in Office documents (also VBA projects in legacy DOC and XLS files), active content in SVG, then the rules in Rules.

An instance is immutable and thread-safe; register one per policy as a singleton. The check does not replace a request size limit in the web server, generated file names, re-encoding images or virus scanning.

Examples

validator.Validate(pngBytes, "photo.png").IsSafe;        // true
validator.Validate(exeBytes, "photo.png").Rejection;     // DangerousContent
validator.Validate(pngBytes, "photo.php.png").Rejection; // DoubleExtension

Remarks

An SVG is scanned only as far as content goes; pass the whole file or use Validate(Stream, string).
