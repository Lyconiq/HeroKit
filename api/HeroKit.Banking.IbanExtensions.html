IsValidIban(string?)

Determines whether a string is a valid IBAN (ISO 13616). Spaces are ignored and lowercase letters are accepted.

public static bool IsValidIban(this string? value)

Parameters

value string

The string to check.

Returns

bool

true if the string is a valid IBAN; otherwise, false. Null or empty input returns false.

Examples

"TR33 0006 1005 1978 6457 8413 26".IsValidIban(); // true
"TR330006100519786457841327".IsValidIban();       // false

Remarks

The check covers structure (country letters, check digits, alphanumeric BBAN, length 15 to 34) and the mod-97 checksum. For Turkey ("TR") the length must be 26 and the reserved fifth character must be '0'.
