WithAdditionalHolidays(IEnumerable<PublicHoliday>)

Returns a copy of the country whose holiday calendar also contains the given days, for example administrative leave ("idari izin") or company holidays. A given day replaces a holiday of the country on the same date. The country itself does not change.

public Country WithAdditionalHolidays(IEnumerable<PublicHoliday> holidays)

Parameters

holidays IEnumerable<PublicHoliday>

The days to add; set IsHalfDay for an afternoon off.

Returns

Country

A copy with every other rule of this country.

Examples

Country turkeyWithLeave = Countries.Turkey.WithAdditionalHolidays([new(new DateOnly(2026, 5, 18), "İdari izin", false)]);
new DateOnly(2026, 5, 18).IsBusinessDay(turkeyWithLeave); // false: 18 May is added as administrative leave

Exceptions

NotSupportedException

The country has no holiday calendar.

ArgumentException

A date is given more than once, or a name is empty.

ArgumentOutOfRangeException

A date is outside the supported years of the calendar.
