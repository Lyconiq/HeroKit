Examples

var registry = new FileTypeRegistry(); // the built-in types
registry.Register(new FileType("Sketch document", "application/x-sketch", FileTypeCategory.Document, "sketch")
{
    Detectors = [new ZipEntryDetector("document.json")],
    Parent = FileTypes.Zip,
});
services.AddSingleton(registry);

Remarks

Default holds the built-in types and is what the static FileTypes methods use. Create your own instance to keep custom types out of the shared registry, for example per tenant, in tests or through dependency injection.

The registry is thread-safe. Register(FileType) replaces an internal snapshot, so readers never see a half-updated state.

Detection reads magic bytes from the start of a file. It is a first check, not a proof: a file can be crafted to match a type.

Remarks

The content fits when the detected type is the extension's type, or one is built on the other through Parent: a ".docx" whose entries are beyond the header is accepted as ZIP, and a ".csv" is accepted as plain text.
