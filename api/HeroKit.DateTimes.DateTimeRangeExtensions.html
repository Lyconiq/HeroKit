Age(DateOnly, DateOnly)

Calculates the completed years between a birth date and a reference date. A Feb 29 birthday counts as completed on Mar 1 in non-leap years.

public static int Age(this DateOnly birthDate, DateOnly asOf)

Parameters

birthDate DateOnly

The birth date.

asOf DateOnly

The reference date.

Returns

int

The number of completed years.

Examples

new DateOnly(2000, 2, 29).Age(new DateOnly(2026, 3, 1)); // 26

Exceptions

ArgumentOutOfRangeException

Thrown when asOf is earlier than birthDate.
