Remarks

Every conversion comes in two forms. ToX is lenient: it returns a default value for null, empty or invalid input and never throws. TryToX reports success: it returns false for null, empty or invalid input and never throws. Parsing uses the invariant culture unless a format provider is passed.

ToDecimal(string?, decimal, IFormatProvider?)

Converts a string to a decimal.

public static decimal ToDecimal(this string? value, decimal defaultValue = 0, IFormatProvider? provider = null)

Parameters

value string

The string to convert.

defaultValue decimal

The value returned when the string is null, empty or invalid.

provider IFormatProvider

The format provider for strict parsing, or null for the flexible rule.

Returns

decimal

The decimal, or defaultValue.

Examples

"1.234,56".ToDecimal();  // 1234.56
"1234.56".ToDecimal();   // 1234.56
"abc".ToDecimal(-1m);    // -1

Remarks

Without a provider the conversion is flexible: a comma is the decimal separator when present ("1.234,56"), otherwise a dot is ("1234.56"). With a provider the string is parsed strictly with that culture.
