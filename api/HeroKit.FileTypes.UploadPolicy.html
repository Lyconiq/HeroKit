Properties

AllowMacros

Gets whether documents with macros are accepted: macro-enabled types (HasMacros, for example DOCM and XLSM) and legacy DOC and XLS files with a VBA project. Defaults to false.

public bool AllowMacros { get; init; }

Property Value

bool

Remarks

A legacy file is searched for a VBA project only when its directory is available: pass the whole file as a span, or a seekable stream. Excel 4.0 (XLM) macro sheets and PowerPoint 97-2003 macros are not found.

AllowUnknownContent

BlockedExtensions

Gets the extensions that are always rejected, in lower case without a dot. Extensions of program and script types (IsExecutable) in the registry are rejected as well. Defaults to DefaultBlockedExtensions.

public IReadOnlySet<string> BlockedExtensions { get; init; }

MaxLength

Gets the largest allowed file in bytes, or null for no limit. Defaults to null.

public long? MaxLength { get; init; }

Property Value

long?

Remarks

The length of a span is its length; the length of a stream is read only when the stream can seek. Also limit the request body in the web server (for example [RequestSizeLimit] in ASP.NET Core), so a large upload is refused before it is read.
