EqualsIgnoreCase(string?, string?, CultureInfo)

Compares two strings for equality, ignoring case with the rules of the given culture.

public static bool EqualsIgnoreCase(this string? value, string? other, CultureInfo culture)

Parameters

value string

The first string.

other string

The second string.

culture CultureInfo

The culture whose casing rules are used. With tr-TR, "I" matches "ı" and "İ" matches "i".

Returns

bool

True if both strings are null or equal ignoring case; otherwise false.

Examples

"IŞIK".EqualsIgnoreCase("ışık", CultureInfo.GetCultureInfo("tr-TR")); // true
"FILE".EqualsIgnoreCase("file", CultureInfo.InvariantCulture);        // true
